Virtual Pro Wrestling 64 Deluxe for Linux (64-bit Intel/AMD)

1. Unpack this folder anywhere you like (your home folder is fine).
2. Double-click VPW64Deluxe, or run ./VPW64Deluxe in a terminal from this folder.
3. The first time, the launcher asks for your own Virtual Pro Wrestling 64 Deluxe ROM
   (.z64). Nothing from the game ships with this download.

Settings and saves are kept in ~/.config/VPW64Deluxe.
Optional menu shortcut: run ./install-shortcut.sh once to add VPW64 Deluxe to your
application menu (it only writes to ~/.local/share).

Needs a desktop with Vulkan graphics drivers (any normal Linux desktop from 2022 on).
